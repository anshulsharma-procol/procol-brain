# Hackathon Demo

## Ticket

Customer: ABC Corp

Issue:
Invoice GST calculation is incorrect.

## Flow

1. Customer ticket arrives
2. Brain analyzes ticket
3. Brain asks Clara for product/customer context
4. Clara returns expected GST configuration
5. Brain delegates investigation to Dev Agent
6. Dev Agent identifies root cause
7. Dev Agent creates PR
8. Brain delegates validation to QA Agent
9. QA runs tests
10. QA passes
11. Manager approves fix
12. Brain resolves ticket
13. Customer receives update
